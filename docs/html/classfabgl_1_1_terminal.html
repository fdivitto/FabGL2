Detailed Description

An ANSI-VT100 compatible display terminal.

Implements most of the common ANSI, VT52, VT100, VT200, VT300, VT420 and VT500 escape codes: non-CSI codes (RIS, IND, DECID, DECDHL, etc.), CSI codes (private modes, CUP, TBC, etc.), CSI-SGR codes (bold, italic, blinking, etc.) and DCS codes (DECRQSS, etc.).
PS/2 keyboard virtual keys are translated to the corresponding ANSI or VT codes (keypad, cursor keys, function keys, etc.).

Terminal can receive the codes to display from a serial port, or it can be driven directly by the application. Likewise, keyboard codes can be sent to a serial port or delivered directly to the application.

By default it supports 80x25 or 132x25 characters at 640x350. Any other resolution and text buffer size is supported by specifying a custom font.

Three cursor styles are available (block, underline and bar), each either blinking or steady.

Terminal derives from Stream, so applications can use all the Stream and Print input and output methods.

Terminal passes 95 of the 110 tests of the VTTEST VT100/VT102 Compatibility Test Score Sheet.

Example: 

fabgl::VGAController VGAController;
fabgl::PS2Controller PS2Controller;
fabgl::Terminal      Terminal;

// 80x25 loop-back terminal: what you type on the keyboard is shown on the display
extern "C" void app_main()
{
  PS2Controller.begin(PS2Preset::KeyboardPort0);

  VGAController.begin();
  VGAController.setResolution(VGA_640x350_70HzAlt1);

  Terminal.begin(&VGAController);
  Terminal.connectLocally();      // enables Terminal.read(), available(), etc.
  Terminal.enableCursor(true);

  while (true) {
    int c = Terminal.read(-1);    // wait for a key
    switch (c) {
      case 0x7F:       // DEL -> backspace + ESC[K
        Terminal.write("\\b\e[K");
        break;
      case 0x0D:       // CR  -> CR + LF
        Terminal.write("\r\n");
        break;
      case 32 ... 126: // printable chars
        Terminal.write(c);
        break;
    }
  }
}
