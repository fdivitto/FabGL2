◆ setGlyphOptions()

void setGlyphOptions ( GlyphOptions options)

Sets drawing options for the next glyphs.

Glyph options change how glyphs are rendered, applying effects such as bold, italic, inversion, double width or double height.
Since Canvas draws text using glyphs, these options also affect how text is rendered.

Parameters
optionsBit field specifying multiple options

Example: 

// Draw "Hello World!"
Canvas.setGlyphOptions(GlyphOptions().FillBackground(true).DoubleWidth(1));
Canvas.drawText(20, 20, "Hello World!");
