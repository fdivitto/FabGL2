static

Mounts the filesystem of the SD Card.

Parameters
formatOnFailIf true, the SD Card is formatted when it cannot be mounted.
mountPathMount directory (e.g. "/sdcard").
maxFilesMaximum number of files that can be open at the same time (default 4).
allocationUnitSizeAllocation unit size (default 16K).
MISOPin for MISO signal (default 16 for WROOM-32, 2 for PICO-D4).
MOSIPin for MOSI signal (default 17 for WROOM-32, 12 for PICO-D4).
CLKPin for CLK signal (default 14).
CSPin for CS signal (default 13).
Returns
True on success.

Example: 

// Mount SD Card
FileBrowser::mountSDCard(false, "/sdcard");
