Audio

Interactive sound mixer built with the FabGL GUI: each window is an audio channel with its own waveform generator, volume and frequency, all mixed together by fabgl::SoundGenerator in real time.

At startup there are four channels, plus the Main Controls window. All the channels start disabled: tick Enable in a channel to hear it.

Controls

Each Channel window:

Control Function
Volume Channel volume, 0...127
Type Generator: Sine, Square, Triangle, Sawtooth, Noise, or a sampled sound: Loop (drum loop), Speech, Mario
Freq Frequency, 0...8000 Hz (for the sampled sounds it changes the playback speed)
Enable Turns the channel on and off

Main Controls window:

Control Function
Add Channel Adds a new channel window (until the memory runs out)
Reset Restarts the board
Enable Global play/stop
Vol (vertical slider) Master volume, 0...127

Windows can be moved, minimized and maximized with the mouse; with the keyboard, Tab moves the focus and the arrow keys move the sliders.

What it demonstrates

  • fabgl::SoundGenerator with any number of channels (attach() / detach(), setVolume(), play())
  • The waveform generators: SineWaveformGenerator, SquareWaveformGenerator, TriangleWaveformGenerator, SawtoothWaveformGenerator, NoiseWaveformGenerator, and SamplesGenerator for 8-bit sampled sounds (converted from WAV with tools/wav2header)
  • GUI: frames, sliders, combo boxes, check boxes, buttons, message boxes

Hardware

  • VGA output (default pins)
  • Audio output on GPIO25 (connect an amplifier or active speakers through a capacitor)
  • PS/2 mouse on port 1 (recommended) and/or PS/2 keyboard on port 0

Build

See Building the examples.

79 static int y = 4, x = 4;
80 static int startingFreq = 150;

82 app()->moveWindow(this, x, y);

98 volumeLabel->setTextFmt("Volume %d", volumeSlider->position());

102 volumeSlider->setup(0, 127, 16);
103 volumeSlider->setPosition(100);

105 // generator combobox
106 new uiStaticLabel(this, "Type", Point(230, 20));

147 void setGenerator(int index) {
148 soundGenerator.detach(curGen);
149 switch (index) {
150 case 0:
151 curGen = &sine;
152 break;
153 case 1:
154 curGen = &square;
155 break;
156 case 2:
157 curGen = &triangle;
158 break;
159 case 3:
160 curGen = &sawtooth;
161 break;
162 case 4:
163 curGen = &noise;
164 break;
165 case 5:
166 curGen = &loop;
167 break;
168 case 6:
169 curGen = &speech;
170 break;
171 case 7:
172 curGen = &mario;
173 break;
174 }
175 soundGenerator.attach(curGen);
176 curGen->enable(enableCheck->checked());
177 curGen->setFrequency(frequencySlider->position());
178 }
179};
