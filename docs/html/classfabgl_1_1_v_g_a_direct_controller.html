Detailed Description

Base class for direct-draw VGA controllers.

A direct-draw VGA controller paints the screen in real time, scanline by scanline. An interrupt is generated every two scanlines. Put the drawing code inside a callback and assign it with setDrawScanlineCallback().

See DirectVGA example (examples/VGA/DirectVGA).

Examples
VGA/DirectVGA/main/DirectVGA.cpp, and VGA/DirectVGA_ElMuro/main/DirectVGA_ElMuro.cpp.
