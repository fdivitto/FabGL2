Detailed Description

Base class for PS/2 devices (such as mice and keyboards).

PS2Device connects to one port of the PS/2 controller (fabgl::PS2Controller).
The PS/2 controller uses the ULP coprocessor and RTC slow memory to communicate with the PS/2 device.
