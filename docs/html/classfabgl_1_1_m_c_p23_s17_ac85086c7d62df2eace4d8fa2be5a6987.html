◆ enableInterrupt()

void enableInterrupt ( int gpio,
MCPIntTrigger trigger,
bool defaultValue = false,
uint8_t hwAddr = 0 )

Enables the interrupt on the specified pin.

Interrupt flags are cleared by reading the GPIO or by calling getPortIntCaptured().

Parameters
gpioInput pin to use as interrupt source (MCP_A0...MCP_A7 and MCP_B0...MCP_B7)
triggerInterrupt trigger type. MCPIntTrigger::DefaultChange triggers an interrupt when the pin differs from defaultValue; MCPIntTrigger::PreviousChange triggers an interrupt whenever the pin changes.
defaultValueDefault value used when trigger is MCPIntTrigger::DefaultChange (false = low, true = high)
hwAddrOptional hardware device address

Example: 

// INTA and INTB are driven high on interrupt
io.setINTActiveHigh(true);

// INTB is high whenever B1 changes its value
io.enableInterrupt(MCP_B1, MCPIntTrigger::PreviousChange);

// INTA is high whenever A2 is high
io.enableInterrupt(MCP_A2, MCPIntTrigger::DefaultChange, false);
