Examples

The examples/ folder contains complete ESP-IDF projects that show how to use every part of the library: from small demos of a single feature to complete applications such as emulators of retro computers, terminals and games. Each example has its own page with the purpose of the demo, what it demonstrates, the required hardware and how to use it (commands, keys, disk images...). The page of each example ends with its source code.

Building the examples

Every folder under examples/ that contains an sdkconfig.defaults file is a standalone ESP-IDF project (ESP-IDF 6.1 or newer):

. $IDF_PATH/export.sh
cd examples/VGA/SpaceInvaders
idf.py build flash monitor

To build an example copied outside the FabGL repository, set the FABGL_PATH environment variable to the root of the repository.

To build or clean several examples at once:

tools/build_examples.sh # all examples
tools/build_examples.sh VGA/ # VGA examples only
tools/clean_examples.sh # remove the build output of all examples

Some examples ship a partitions.csv file (larger application partition, SPIFFS partition for files): it is used automatically by idf.py.

Default pins (as on the TTGO VGA32 board), used by all the examples:

Signal GPIO
VGA Red (MSB, LSB) 22, 21
VGA Green (MSB, LSB) 19, 18
VGA Blue (MSB, LSB) 5, 4
VGA HSync, VSync 23, 15
PS/2 port 0 (keyboard) CLK, DATA 33, 32
PS/2 port 1 (mouse) CLK, DATA 26, 27
Audio output (DAC) 25 (23 with composite video, sigma-delta)
Composite video output 25

The "default pins" mentioned in the example pages are the ones of this table.
