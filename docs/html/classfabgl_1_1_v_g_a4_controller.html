Detailed Description

VGA bitmapped display controller with 4 colors.

This VGA controller displays only 4 colors, but at the same resolution it requires 1/4 of the RAM used by VGAController. Each pixel is represented by 2 bits: an index into a palette of 4 colors. Each byte of the frame buffer contains four pixels. For example, a 640x480 frame buffer requires about 75 KB of RAM.

VGA4Controller uses up to 11% of one CPU core (measured at 640x480@60Hz), leaving more free RAM to the application.

This example initializes the VGA controller with 64 colors (4 visible at the same time) at 640x480: 

fabgl::VGA4Controller displayController;
// the default pinout assigns GPIO22 and GPIO21 to red, GPIO19 and GPIO18 to green, GPIO5 and GPIO4 to blue, GPIO23 to HSync and GPIO15 to VSync
displayController.begin();
displayController.setResolution(VGA_640x480_60Hz);
