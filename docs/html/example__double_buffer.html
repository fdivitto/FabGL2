DoubleBuffer

Benchmark of the drawing primitives with double buffering (flicker-free full screen animation) at 320x200, 64 colors.

Three tests run one after the other in an endless loop. Each test adds a new object every 5 frames until its maximum is reached, then moves to the next test. The yellow label at the top shows the number of objects, the test name and the measured frames per second:

Test Content
Balls Up to 300 filled circles bouncing around
Polygons Rotating filled polygons with random shape and color
Sprites Moving sprites

The demo runs on its own: there are no controls.

What it demonstrates

  • VGAController::setResolution(..., doubleBuffered = true) and Canvas::swapBuffers()
  • Full-screen redraw at every frame with Canvas::clear(), fillEllipse(), fillPath() and sprites
  • Measuring the drawing throughput (FPS) as the scene gets heavier

Set DOUBLEBUFFERING to 0 in DoubleBuffer.cpp to see the same scene without double buffering (the flickering becomes visible).

Hardware

  • VGA output (default pins)

See Building the examples.

75void loop()
76{
77 static int64_t stime = esp_timer_get_time();
78 static int FPS = 0;
79 static int FPSCounter = 0;
80 static int testIndex = 0;
81 static Test * test = new BallsTest;
82
83 if (test->nextState() == false) {
84 delete test;
85 ++testIndex;
86 switch (testIndex) {
87 case 1:
88 test = new PolygonsTest;
89 break;
90 case 2:
91 test = new SpritesTest;
92 break;
93 default:
94 testIndex = 0;
95 test = new BallsTest;
96 break;
97 }
98 }
99
100 if (esp_timer_get_time() - stime > 1000000) {
101 // calculate FPS
102 FPS = FPSCounter;
103 stime = esp_timer_get_time();
104 FPSCounter = 0;
105 }
106 ++FPSCounter;
107
108 test->update();
109
110 // display test state and FPS
111 canvas.setPenColor(Color::Blue);
112 canvas.setBrushColor(Color::Yellow);
113 canvas.drawTextFmt(80, 5, " %d %s at %d FPS ", test->testState(), test->name(), FPS);
114
115 if (DOUBLEBUFFERING)
116 canvas.swapBuffers();
117}
