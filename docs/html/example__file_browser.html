FileBrowser

A small file manager with a graphical user interface. It browses the internal flash (SPIFFS) and the SD card, manages files and directories and downloads files from the Internet (HTTP and HTTPS).

The window (400x300, 64 colors) contains the file browser on the left, the command buttons on the right and, at the bottom, the used/free space of the current drive and the WiFi status.

Usage

The file browser root shows the available drives: flash (SPIFFS) and SD (SD card, if inserted). Double-click (or press Enter on) a directory to enter it, .. to go up.

Button Action
Create Dir Creates a directory in the current folder
Create Empty File Creates an empty file in the current folder
Rename Renames the selected file or directory
Delete Deletes the selected file or directory (asks a confirmation)
Format Formats the current drive, or the drive selected in the root (asks a confirmation; all data is lost)
Setup WiFi Asks network name and password, saves them in NVS and connects. At the next boot the example connects automatically
Download Asks a URL (HTTP or HTTPS) and downloads the file into the current folder; the file name is the last part of the URL. An error message shows the HTTP code if the download fails

Both drives are formatted automatically if they cannot be mounted.

What it demonstrates

  • uiFileBrowser control, uiApp::inputBox() and messageBox()
  • fabgl::FileBrowser: SPIFFS and SD card mount, directory operations, format(), getFSInfo()
  • fabgl::WiFiConnection, fabgl::Preferences (NVS) and fabgl::HTTPRequest (HTTPS with the certificate bundle, redirects)
  • Memory tuning to run VGA, WiFi, TLS and the SD card together (see sdkconfig.defaults)

Hardware

  • VGA output (default pins)
  • PS/2 keyboard on port 0 and PS/2 mouse on port 1
  • Optional SD card. Default connections (TTGO VGA32 slot): MISO = GPIO16 (2 on PICO-D4 boards), MOSI = GPIO17 (12 on PICO-D4), CLK = GPIO14, CS = GPIO13

Build

The example ships a partitions.csv (2 MB application + SPIFFS). See Building the examples.

206 // connect to wifi using SSID and PSW from Preferences
207 void connectWiFi()
208 {
209 WiFiStatusLbl->setText("WiFi Not Connected");
210 WiFiStatusLbl->labelStyle().textColor = RGB888(255, 0, 0);
211 char SSID[32], psw[32];
212 if (preferences.getString("SSID", SSID, sizeof(SSID)) && preferences.getString("WiFiPsw", psw, sizeof(psw))) {
213 wifi.disconnect();
214 if (wifi.connect(SSID, psw, 16000) == fabgl::WiFiConnectionState::Connected) {
215 WiFiStatusLbl->setTextFmt("Connected to %s, IP is %s", wifi.SSID(), wifi.IPString());
216 WiFiStatusLbl->labelStyle().textColor = RGB888(0, 128, 0);
217 }
218 }
219 WiFiStatusLbl->update();
220 }
221
222 // download from URL. Filename is the last part of the URL
223 void download(char const * URL) {
224 char const * slashPos = strrchr(URL, '/');
225 if (slashPos) {
226 char filename[slashPos - URL + 1];
227 strcpy(filename, slashPos + 1);
228
229 int fullpathLen = fileBrowser->content().getFullPath(filename);
230 char fullpath[fullpathLen];
231 fileBrowser->content().getFullPath(filename, fullpath, fullpathLen);
232 FILE * f = fopen(fullpath, "wb");
233 if (f) {
234 fabgl::HTTPRequest http;
235 http.onData = [&](void const * data, int len) {
236 fwrite(data, 1, len, f);
237 };
238 int httpCode = http.GET(URL);
239 fclose(f);
240 if (httpCode != 200) {
241 remove(fullpath);
242 char msg[64];
243 if (httpCode == 0)
244 snprintf(msg, sizeof(msg), "Connection failed");
245 else
246 snprintf(msg, sizeof(msg), "Server replied with HTTP code %d", httpCode);
247 messageBox("Download failed", msg, "OK", nullptr, nullptr, uiMessageBoxIcon::Error);
248 }
249 updateBrowser();
250 } else
251 messageBox("Download failed", "Cannot create the file", "OK", nullptr, nullptr, uiMessageBoxIcon::Error);
252 }
253 }

255 // show used and free SD space
256 void updateFreeSpaceLabel() {
257 int64_t total, used;
258 FileBrowser::getFSInfo(fileBrowser->content().getCurrentDriveType(), 0, &total, &used);
259 freeSpaceLbl->setTextFmt("%lld KiB used, %lld KiB free", used / 1024, (total - used) / 1024);
260 freeSpaceLbl->update();
261 }

266void setup()
267{
268
269 preferences.begin("FileBrowser", false);
270
271 PS2Controller.begin(PS2Preset::KeyboardPort0_MousePort1, KbdMode::GenerateVirtualKeys);
272
273 DisplayController.begin();
274
275 // keep LOW!!! otherwise there isn't enough memory for WiFi!!!
276 DisplayController.setResolution(VGA_400x300_60Hz);
277
278 // adjust this to center screen in your monitor
279 //DisplayController.moveScreen(-6, 0);
280
281 Canvas cv(&DisplayController);
282 cv.clear();
283 cv.drawText(50, 170, "Initializing...");
284 cv.waitCompletion();
285
286 FileBrowser::mountSDCard(FORMAT_ON_FAIL, SDCARD_MOUNT_PATH);
287 FileBrowser::mountSPIFFS(FORMAT_ON_FAIL, SPIFFS_MOUNT_PATH);
288}
