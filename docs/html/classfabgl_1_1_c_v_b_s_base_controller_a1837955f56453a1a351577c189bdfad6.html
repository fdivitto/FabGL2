◆ suspendBackgroundPrimitiveExecution()

void suspendBackgroundPrimitiveExecution ( )
virtual

Suspends drawings.

Suspends drawing by disabling the vertical sync interrupt.
After calling suspendBackgroundPrimitiveExecution(), adding new primitives may cause a deadlock.
To avoid this, call processPrimitives() frequently.
Calls can be nested: the method maintains a counter.

Implements BitmappedDisplayController.

Reimplemented in CVBSPalettedController.
