◆ setColorForAttribute() [2/2]

void setColorForAttribute ( CharStyle attribute,
Color color,
bool maintainStyle )

Selects a color for the specified attribute.

Specifies the color used when the terminal prints a character with the given attribute. If a character has multiple attributes, the resulting color is undefined. To disable the attribute color, call the other setColorForAttribute() overload.

Parameters
attributeStyle/attribute whose color is set. Only CharStyle::Bold, CharStyle::ReducedLuminosity, CharStyle::Italic and CharStyle::Underline are supported
colorColor of the attribute
maintainStyleIf true, the style is applied as well; if false, only the specified color is applied.
Examples
VGA/Altair8800/main/Altair8800.cpp, and VGA/SimpleTerminalOut/main/SimpleTerminalOut.cpp.
