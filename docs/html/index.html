Demos and Tutorials

FabGL is a graphics library for the ESP32, distributed as an ESP-IDF component (FabGL2 requires ESP-IDF 6.1 or newer).
It provides display drivers for VGA output and for PAL/NTSC color composite video.
It also handles PS/2 keyboards and mice: communication on the PS/2 ports is performed by the ULP coprocessor, leaving both main CPU cores free for the application.
In addition, FabGL includes an audio engine, a Graphical User Interface (GUI), a game engine, an ANSI/VT terminal and emulators of several CPUs and peripherals.

The library supports ESP32 revision 1 and later.

VGA output requires a simple digital-to-analog converter (DAC): three 270 Ohm resistors provide 8 colors, while six resistors provide 64 colors.

Several fixed and variable width fonts are embedded.

The number of sprites is unlimited. However, large sprites or a large number of them reduce the frame rate and may cause flickering.

When enough memory is available (for example at low resolutions such as 320x200), two screen buffers can be allocated to implement double buffering.
In this case drawing primitives always operate on the back buffer.

Unless double buffering is used or this behavior is explicitly disabled, all drawing operations are performed during the vertical retrace, so no flickering is visible.
If the queue of drawing primitives is not completely processed before the vertical retrace ends, processing is suspended and resumed at the next vertical retrace.

The graphical user interface (GUI) supports overlapping windows, mouse handling and many widgets (buttons, edit boxes, checkboxes, combo boxes, list boxes, etc.).

Finally, the sound engine mixes multiple channels into a mono output. Each channel can generate sine, square and other waveforms, or play custom sampled data.
Like VGA output, audio output is generated using DMA: the CPU only mixes the channels and prepares the waveforms.

New to FabGL? Start from the User Guide: it explains how the library is organized and shows how to use each subsystem, from the first program to GUI applications. The "Topics" section groups the classes by subsystem.

Main classes of the FabGL library:

  • fabgl::VGAController, device driver for bitmapped VGA output (64 colors)
  • fabgl::VGA2Controller, device driver for 2-color bitmapped VGA output (low RAM requirements, CPU intensive)
  • fabgl::VGA4Controller, device driver for 4-color bitmapped VGA output (low RAM requirements, CPU intensive)
  • fabgl::VGA8Controller, device driver for 8-color bitmapped VGA output (low RAM requirements, CPU intensive)
  • fabgl::VGA16Controller, device driver for 16-color bitmapped VGA output (low RAM requirements, CPU intensive)
  • fabgl::VGATextController, device driver for text-only VGA output (low RAM requirements, CPU intensive)
  • fabgl::CVBS16Controller, device driver for 16-color PAL/NTSC composite video output
  • fabgl::Canvas, a set of drawing primitives (lines, rectangles, text, bitmaps...)
  • fabgl::Terminal, an ANSI/VT100/VT102 (and later) compatible terminal emulator (see the vttest score)
  • fabgl::Keyboard, which controls a PS/2 keyboard and translates scancodes into virtual keys or ASCII/ANSI codes
  • fabgl::Mouse, which controls a PS/2 mouse
  • fabgl::Scene, an abstract class that handles sprites, timing and collision detection
  • fabgl::uiApp, the base class for Graphical User Interface applications
  • fabgl::SoundGenerator, which generates sound and music
  • fabgl::InputBox, which builds simple UI wizards

Device emulation classes:

  • fabgl::Z80, Zilog Z80 CPU emulator
  • fabgl::i8080, Intel 8080 CPU emulator
  • fabgl::MOS6502, MOS 6502 CPU emulator
  • fabgl::VIA6522, MOS 6522 VIA emulator

Other classes:

  • fabgl::I2C, thread-safe I2C bus driver
  • fabgl::DS3231, DS3231 Real Time Clock driver (based on fabgl::I2C)
  • fabgl::MCP23S17, MCP23S17 16-bit SPI I/O expander driver
  • fabgl::SerialPort, interrupt-driven UART driver with flow control
  • fabgl::UARTStream, fabgl::Stream implementation based on the ESP-IDF UART driver
  • fabgl::Preferences, key/value storage on non-volatile flash (NVS)
  • fabgl::WiFiScanner, fabgl::WiFiConnection, fabgl::TCPClient, fabgl::HTTPRequest and fabgl::ICMP, network helpers
