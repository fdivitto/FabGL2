MouseOnScreen

Shows how to display a mouse pointer on a VGA screen and use it to draw.

The screen (640x350, 64 colors) shows the current pointer coordinates in a small yellow box.

What it demonstrates

  • Mouse::setupAbsolutePositioner(): converts the relative PS/2 mouse movements into absolute screen coordinates and moves the hardware-like mouse cursor drawn by the display controller
  • VGAController::setMouseCursor() and the predefined CursorName shapes
  • Blocking read of the mouse status (Mouse::getNextStatus()), buttons and wheel

Hardware

  • VGA output (default pins)
  • PS/2 mouse on port 1 (CLK = GPIO26, DATA = GPIO27); a wheel mouse is optional

Controls

Mouse action Effect
Left button (hold and move) Draws red pixels at the pointer position
Right button Cycles through the available pointer shapes
Middle button Clears the screen
Wheel Moves the coordinates box up and down

48void setup()
49{
50 DisplayController.begin();
51 DisplayController.setResolution(VGA_640x350_70HzAlt1);
52 //DisplayController.setResolution(VGA_640x240_60Hz); // select to have more free memory
53
54 // Setup mouse
55 PS2Controller.begin();
56 PS2Controller.mouse()->setupAbsolutePositioner(canvas.getWidth(), canvas.getHeight(), true, &DisplayController);
57 DisplayController.setMouseCursor((CursorName)cursor);
58
59 canvas.setBrushColor(Color::Blue);
60 canvas.clear();
61 canvas.selectFont(&fabgl::FONT_8x8);
62 canvas.setGlyphOptions(GlyphOptions().FillBackground(true));
63
64 showCursorPos(PS2Controller.mouse()->status());
65}
66
67
68void loop()
69{
70 MouseStatus status = PS2Controller.mouse()->getNextStatus(-1); // -1 = blocking operation
71
72 // left button writes pixels
73 if (status.buttons.left) {
74 canvas.setPenColor(Color::BrightRed);
75 canvas.setPixel(status.X, status.Y);
76 canvas.moveTo(status.X, status.Y);
77 }
78
79 // right button change mouse shape
80 if (status.buttons.right) {
81 cursor = ((CursorName)cursor == CursorName::CursorTextInput ? 0 : cursor + 1);
82 DisplayController.setMouseCursor((CursorName)cursor);
83 }
84
85 // middle button clear screen
86 if (status.buttons.middle) {
87 canvas.setBrushColor(Color::Blue);
88 canvas.clear();
89 }
90
91 // mouse wheel moves cursor position indicator
92 if (status.wheelDelta != 0) {
93 indicatorY = fabgl::tclamp(indicatorY + status.wheelDelta, 0, canvas.getHeight() - 16);
94 PS2Controller.mouse()->status().wheelDelta = 0;
95 canvas.setBrushColor(Color::Blue);
96 canvas.clear();
97 }
98
99 showCursorPos(status);
100}

107 loop();
