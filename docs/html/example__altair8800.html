Altair8800

Emulator of the MITS Altair 8800 computer with Intel 8080 or Zilog Z80 CPU, 64 KB of RAM, up to four 88-DCDD 8" floppy disk drives and serial I/O boards. It boots <strong>CP/M</strong> (1.4, 2.2, 3), Altair Disk BASIC or Altair DOS from the disk images included in the firmware. Watch it on <a href="https://www.youtube.com/watch?v=y0opVifEyS8" >YouTube</a>. The video output is a 80x25 text terminal (ADM-31 emulation by default) on VGA; the keyboard is a PS/2 keyboard. <h1>Getting started</h1> Flash the example and wait for the <tt>A\></tt> prompt: drive A contains CP/M 2.2, drive B contains games. @icode A>DIR A>B: B>DIR B>LADDER @endicode Some programs to try: <table class="markdownTable"> <tr class="markdownTableHead"> <th class="markdownTableHeadNone"> Disk

Programs

A: CP/M 2.2 (cpm22_dsk)

MBASIC, ASM, MAC, M80/L80, DDT, ED, PIP, STAT, SUBMIT, DUMP, SURVEY, FORMAT, PCGET/PCPUT

B: Games (games_dsk)

LADDER, CATCHUM, ALIENS, OTHELLO, DUMPSTAR, and in MBASIC: STARTRK, LUNAR, CHASE, TICTAK (MBASIC STARTRK)

If a game draws garbage, configure it for the terminal: LADCONF (Ladder) and CATCONF (Catchum) select the terminal type, or change the emulated terminal from the emulator menu.

Disk drives

Drive Default content Writable
A: CP/M 2.2 system disk (image in flash) With an SD card: yes (copied to diskA.dsk on the card). Without: read only
B: Games disk (image in flash) Same as A: (diskB.dsk)
C: diskC.dsk on SD card or SPIFFS Yes. Format it first with FORMAT C:
D: diskD.dsk on SD card or SPIFFS Yes. Format it first with FORMAT D:

The emulator uses the SD card if present, otherwise the internal SPIFFS partition (formatted automatically on first use). Files on drives C: and D: survive a reboot.

Changing the disk images

The included images are selected at compile time with the DRIVE_A ... DRIVE_D defines at the top of main/Altair8800.cpp:

#define DISKFORMAT Disk_338K
#define DRIVE_A cpm22_dsk // image in flash
#define DRIVE_B games_dsk // image in flash
#define DRIVE_C "diskC.dsk" // file on SD card / SPIFFS
#define DRIVE_D "diskD.dsk"

Altair DOS and Disk BASIC ask some questions at boot. Suggested answers are in the comments next to their <tt>\#include</tt> lines in <tt>Altair8800.cpp</tt> (for example Disk BASIC: <tt>MEMORY SIZE?</tt> Enter, <tt>LINEPRINTER?</tt> <tt>C</tt>, then Enter to the remaining questions). To add your own image, convert the raw Altair .dsk file to a C header containing a const uint8_t name[] = { ... }; array (for example with xxd -i), include it and assign it to a drive.

Emulator menu (F12 or Pause)

Press F12 or Pause at any time to open the emulator menu. Press the letter of an option, Enter to go back to the emulated machine.

Key Option
Z Reset the Altair (reboot)
S Send a disk image to the serial port (USB)
R Receive a disk image from the serial port (USB)
F Format the file system (SD card or SPIFFS): deletes all the disk files!
U CPU: Z80 / i8080 (reset required)
P Real CPU speed: emulate the original 2 MHz speed, or run as fast as possible
T Terminal emulation: ANSI, ADM 3A, ADM 31, Hazeltine 1500, Osborne, Kaypro, VT52, ANSI Legacy
K Keyboard layout
C Colors: Green/Black, Yellow/Black, White/Black, Black/White, Yellow/Blue, Black/Yellow
L Rows: 24, 25 or max
G CRT mode (retro scanlines, only with the graphical display controller, see below)
O Reset the configuration to the defaults

The settings are saved in NVS.

Transferring files with a PC

The Altair has three serial boards: SIO at port 00h (TTY) and 10h (CRT) are connected to the screen and keyboard, SIO at port 12h is connected to the USB serial port (115200 baud). The scripts in tools use it (they need Python with pyserial, and xmodem for transfile.py; they are written for Python 2):

Single files (XMODEM): run PCGET (receive) or PCPUT (send) on the Altair, then on the PC:

A>PCGET MYFILE.COM (on the Altair)
python tools/transfile.py MYFILE.COM to /dev/ttyUSB0 (on the PC)
A>PCPUT MBASIC.COM (on the Altair)
python tools/transfile.py MBASIC.COM from /dev/ttyUSB0 (on the PC)

Whole disk images: open the emulator menu and choose R (receive) or S (send) and the drive letter, then on the PC:

python tools/transdisk.py mydisk.dsk to /dev/ttyUSB0 (PC -> Altair, after "R")
python tools/transdisk.py mydisk.dsk from /dev/ttyUSB0 (Altair -> PC, start this before "S")

Close any serial monitor before running the scripts.

What it demonstrates

  • The fabgl::i8080 and fabgl::Z80 CPU cores
  • fabgl::Terminal emulations (ADM-31, ADM-3A, VT52, ...) used as the console of an emulated computer
  • fabgl::VGATextController: 80x25 text with a very small memory footprint. Comment out #define USE_TEXTUAL_DISPLAYCONTROLLER to use fabgl::VGA16Controller instead (enables the CRT mode)
  • fabgl::FileBrowser (SD card / SPIFFS) for writable disk files, fabgl::Preferences for the settings

Hardware

  • VGA output (default pins)
  • PS/2 keyboard on port 0 (CLK = GPIO33, DATA = GPIO32)
  • Optional SD card (TTGO VGA32 slot: MISO = GPIO16 (2 on PICO-D4), MOSI = GPIO17 (12 on PICO-D4), CLK = GPIO14, CS = GPIO13)

Build

The example ships a partitions.csv (2 MB application + SPIFFS for the writable disks). See Building the examples.

271// shown pressing PAUSE
272void emulator_menu()
273{
274 bool resetRequired = false;
275 bool changedRowsCount = false;
276
277 for (bool loop = true; loop; ) {
278
279 diskDrive.flush();
280
281 Terminal.setTerminalType(TermType::ANSILegacy);
282
283 Terminal.write("\r\n\n\e[97m\e[40m ** Emulator Menu **\e[K\r\n\e[K\n");
284 Terminal.write( "\e[93m Z \e[37m Reset\e[K\n\r");
285 Terminal.write( "\e[93m S \e[37m Send Disk to Serial\e[K\n\r");
286 Terminal.write( "\e[93m R \e[37m Get Disk from Serial\e[K\n\r");
287 Terminal.write( "\e[93m F \e[37m Format FileSystem\e[K\n\r");
288 Terminal.printf("\e[93m U \e[37m CPU: \e[33m%s\e[K\n\r", getCPU() == 1 ? "Z80" : "i8080");
289 Terminal.printf("\e[93m P \e[37m Real CPU Speed: \e[33m%s\e[K\n\r", getRealCPUSpeed() ? "YES" : "NO");
290 Terminal.write("\e[6A"); // cursor UP
291 Terminal.printf("\t\t\t\t\t\e[93m T \e[37m Terminal: \e[33m%s\e[K\n\r", SupportedTerminals::names()[(int)getTerminalEmu()] );
292 Terminal.printf("\t\t\t\t\t\e[93m K \e[37m Keyboard Layout: \e[33m%s\e[K\n\r", SupportedLayouts::names()[getKbdLayoutIndex()] );
293 #ifndef USE_TEXTUAL_DISPLAYCONTROLLER
294 Terminal.printf("\t\t\t\t\t\e[93m G \e[37m CRT Mode: \e[33m%s\e[K\n\r", getEmuCRT() ? "YES" : "NO");
295 #endif
296 Terminal.printf("\t\t\t\t\t\e[93m C \e[37m Colors: \e[33m%s\e[K\n\r", ColorsStr[getColorsIndex()] );
297 Terminal.printf("\t\t\t\t\t\e[93m L \e[37m Rows: \e[33m%d\e[K\n\r", getRowsCount() <= 0 ? Terminal.getRows() : getRowsCount());
298 Terminal.write( "\t\t\t\t\t\e[93m O \e[37m Reset Configuration\e[K\n\r");
299
300 Terminal.write("\n\n\e[97mPlease select an option (ENTER to exit): \e[K\e[92m");
301 int ch = toupper(Terminal.read());
302 Terminal.write(ch);
303 Terminal.write("\n\r");
304 switch (ch) {
305
306 // 1. Send a disk image to serial port (console UART)
307 // 2. Receive a disk image from serial port (console UART)
308 case 'S':
309 case 'R':
310 {
311 Terminal.write("Select a drive (A, B, C, D...): ");
312 char drive = toupper(Terminal.read());
313 if (ch == 'S') {
314 Terminal.printf("\n\rSending drive %c...\n\r", drive);
315 diskDrive.sendDiskImageToStream(drive - 'A', &Console);
316 } else if (ch == 'R') {
317 Terminal.printf("\n\rReceiving drive %c...\n\r", drive);
318 diskDrive.receiveDiskImageFromStream(drive - 'A', &Console);
319 }
320 break;
321 }
322
323 // Format FileSystem
324 case 'F':
325 Terminal.write("\e[91mFormat deletes all disks and files in your SD or SPIFFS!\e[92m\r\nAre you sure? (Y/N)");
326 if (toupper(Terminal.read()) == 'Y') {
327 Terminal.write("\n\rFormatting...");
328 Terminal.flush();
329 FileBrowser::format(FileBrowser::getDriveType(basepath), 0);
330 resetRequired = true;
331 }
332 break;
333
334 // Reset
335 case 'Z':
336 Terminal.write("Resetting the Altair. Are you sure? (Y/N)");
337 if (toupper(Terminal.read()) == 'Y')
338 esp_restart();
339 break;
340
341 // Real CPU speed
342 case 'P':
343 preferences.putBool("realSpeed", !getRealCPUSpeed());
344 setupRealCPUSpeed();
345 break;
346
347 // Emulate CRT
348 case 'G':
349 preferences.putBool("emuCRT", !getEmuCRT());
350 resetRequired = true;
351 break;
352
353 // CPU
354 case 'U':
355 preferences.putInt("CPU", getCPU() ^ 1);
356 resetRequired = true;
357 break;
358
359 // Terminal emulation
360 case 'T':
361 {
362 int termIndex = (int)getTerminalEmu() + 1;
363 if (termIndex > MaxTermIndex)
364 termIndex = 0;
365 preferences.putInt("termEmu", termIndex);
366 break;
367 }
368
369 // Keyboard layout
370 case 'K':
371 {
372 int kbdLayIndex = getKbdLayoutIndex() + 1;
373 if (kbdLayIndex >= SupportedLayouts::count())
374 kbdLayIndex = 0;
375 preferences.putInt("kbdLay", kbdLayIndex);
376 setupKbdLayout();
377 break;
378 }
379
380 // Colors
381 case 'C':
382 {
383 int colorsIndex = getColorsIndex() + 1;
384 if (colorsIndex > MaxColorsIndex)
385 colorsIndex = 0;
386 preferences.putInt("colors", colorsIndex);
387 break;
388 }
389
390 // Rows
391 case 'L':
392 {
393 int rows = getRowsCount() + 1;
394 if (rows < 24)
395 rows = 24; // min
396 if (rows > 25)
397 rows = 0; // max
398 preferences.putInt("rowsCount", rows);
399 changedRowsCount = true;
400 break;
401 }
402
403 // Reset configuration
404 case 'O':
405 preferences.clear();
406 resetRequired = true;
407 break;
408
409 default:
410 loop = false;
411 break;
412
413 }
414 }
415
416 if (resetRequired) {
417 Terminal.write("Reset required. Reset now? (Y/N)");
418 if (toupper(Terminal.read()) == 'Y') {
419 diskDrive.detachAll();
420 esp_restart();
421 }
422 }
423
424 Terminal.localWrite("\n");
425
426 if (changedRowsCount) {
427 setupRowsCount();
428 Terminal.clear();
429 Terminal.write("Clear screen required. Settings applied.\r\n\e\n");
430 }
431
432 setupTerminalColors();
433 setupTerminalEmu();
434}

466void attachDisk(int drive, void const * data)
467{
468 auto filename = (char const *)data;
469 auto dskimage = (uint8_t const *) data;
470
471 FileBrowser fb(basepath);
472
473 if (dskimage[0] >= 0x80) {
474 // "data" is a disk image
475 if (FileBrowser::getDriveType(basepath) == fabgl::DriveType::SDCard) {
476 // when storage is SD Card, copy read only disk image into a file, if doesn't already exist
477 char newfilename[10] = { 'd', 'i', 's', 'k', (char)('A' + drive), '.', 'd', 's', 'k' };
478 Terminal.printf("\r\nAttaching disk %c to %s...", 'A' + drive, newfilename);
479 auto sz = fb.getFullPath(newfilename, nullptr, 0);
480 char newfilenamePath[sz];
481 fb.getFullPath(newfilename, newfilenamePath, sz);
482 diskDrive.attachFileFromImage(drive, newfilenamePath, dskimage);
483 } else {
484 // when storage is SPIFFS just mount image as Read Only image
485 diskDrive.attachReadOnlyBuffer(drive, dskimage);
486 }
487 } else {
488 if ((uint8_t)filename[0] < 0x80) {
489 // "data" is a filename
490 Terminal.printf("\r\nAttaching disk %c to %s...", 'A' + drive, filename);
491 Terminal.flush();
492 auto sz = fb.getFullPath(filename, nullptr, 0);
493 char filenamePath[sz];
494 fb.getFullPath(filename, filenamePath, sz);
495 diskDrive.attachFile(drive, filenamePath);
496 }
497 }
498}

501void loop()
502{
503 if (FileBrowser::mountSDCard(FORMAT_ON_FAIL, SDCARD_MOUNT_PATH))
