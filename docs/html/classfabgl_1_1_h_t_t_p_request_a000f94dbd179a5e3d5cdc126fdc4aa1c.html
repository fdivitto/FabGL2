◆ open()

int open ( char const * URL,
int64_t rangeStart = 0 )

Opens a streaming GET request (follows redirects).

After this call, use read() to get the content and close() to release the connection. HTTPS is supported through the ESP-IDF certificate bundle.

Example: 

fabgl::HTTPRequest http;
if (http.open("http://www.fabglib.org/index.html") == 200) {
  uint8_t buf[512];
  int len;
  while ((len = http.read(buf, sizeof(buf))) > 0)
    fwrite(buf, 1, len, file);
}
http.close();

To resume an interrupted download, pass the number of bytes already received as rangeStart: the request then asks only the remaining part (HTTP Range header) and a server that supports it replies 206 (Partial Content), with contentLength() reporting the remaining length.

Parameters
URLThe page or file to retrieve
rangeStartFirst byte to retrieve (0 = whole content)
Returns
The HTTP status code (0 = connection failure)
