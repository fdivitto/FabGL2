About the game

I know I'm a speccy person. But It was too strong the temptation to do it on 320x200 with 8 sprites like a Mocodore 64. :-DDD

I've also simulated the 64 SID sound with ADSR wave definitions.

Maybe I will create some fun version for spectrum (or spectrum next), mocodore or for super-modern super-computers like the raspberry with raylib.

Game controls

Up to two players race at the same time, one on the left lane and one on the right lane. On the home screen each player moves their controller left or right to pick a side, then presses fire (or accelerate) to start. If nobody touches anything the attract mode (hall of fame) starts.

Controller Accelerate Brake Steer Fire / start
Mouse - easiest to win Left button Right button Move left / right Left button
Cursor keys Up Down Left / Right Right Shift
Keys QAOP - so speccy Q A O / P Space
Keys ASTF T F A / S T
Joystick Fire Down Left / Right Fire

The joystick is a classic Atari 2600 joystick connected to the GPIOs: JOY_LEFT = 13, JOY_RIGHT = 2, JOY_DOWN = 14, JOY_FIRE = 12 (change them at the top of ClassicRacer.cpp).

During the race:

Key Action
F1 Pause / resume
F2 Sound on / off
Esc Abort the race

Play with friends or family is always more funny. Create your competitions.

Game score

To win you have to advance 200 cars before your adversary

Each car will give you more or less score depending on your speed

If you arrive to the finish line without crashing a sweet bonus is waiting for you.

Hall of fame

Only game winners enter the hall of fame.

If you have an excellent score but you don't win. HOF is not for you :-D

Scores are stored in spiffs

FabGL notes

This example shows a complete game made with FabGL: sprites over a 320x200 64-color screen (fabgl::VGAController), an ADSR "sound chip" built on fabgl::SoundGenerator (see SoundChipSimulator), reusable game controller classes for keyboard, mouse and GPIO joystick (controllers.h) and the hall of fame stored in a SPIFFS partition (the example ships a partitions.csv).

Hardware: VGA output (default pins), audio on GPIO25, PS/2 keyboard on port 0 and/or PS/2 mouse on port 1, optional joystick.

Build: see Building the examples.
