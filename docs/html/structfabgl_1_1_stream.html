Detailed Description

Abstract byte stream with Arduino-like read and print methods.

Implemented by fabgl::Terminal and fabgl::UARTStream. Besides the methods of fabgl::Print (write(), print(), println(), printf()), a Stream provides available(), read(), peek() and readBytes().
