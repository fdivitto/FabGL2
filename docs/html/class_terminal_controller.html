Detailed Description

TerminalController controls a Terminal object directly, without the application having to send escape sequences.

TerminalController requires FabGL-specific sequences to be enabled (the default) and works regardless of the selected terminal emulation.

Example: 

// Write "Hello" at 10, 10
TerminalController termctrl(&Terminal);
termctrl.setCursorPos(10, 10);
Terminal.write("Hello");
