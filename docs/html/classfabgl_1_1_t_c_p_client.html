Detailed Description

Simple TCP client based on BSD sockets (lwIP).

Example: 

fabgl::TCPClient client;
if (client.connect("towel.blinkenlights.nl", 23)) {
  while (client.connected()) {
    if (client.available())
      putchar(client.read());
  }
}
