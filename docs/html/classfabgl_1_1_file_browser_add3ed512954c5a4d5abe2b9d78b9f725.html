◆ getFSInfo()

bool getFSInfo ( DriveType driveType,
int drive,
int64_t * total,
int64_t * used )
static

Gets the total and used space of a filesystem.

Parameters
driveTypeStorage type (SPI Flash or SD Card).
driveDrive number (can be 0 when only one filesystem is mounted).
totalReceives the total space of the filesystem, in bytes.
usedReceives the used space of the filesystem, in bytes.
Returns
True on success.

Example: 

// print used and free space on SPIFFS (Flash)
int64_t total, used;
FileBrowser::getFSInfo(fabgl::DriveType::SPIFFS, 0, &total, &used);
printf("%lld KiB used, %lld KiB free", used / 1024, (total - used) / 1024);

// print used and free space on SD Card
int64_t total, used;
FileBrowser::getFSInfo(fabgl::DriveType::SDCard, 0, &total, &used);
printf("%lld KiB used, %lld KiB free", used / 1024, (total - used) / 1024);
