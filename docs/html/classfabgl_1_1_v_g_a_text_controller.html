Detailed Description

VGA text-only display controller.

The text-only VGA controller displays only text, but requires less than 50 KB of RAM. The resolution is fixed at 640x480, with 80 columns, a selectable number of rows and 16 colors.

Text-only output is CPU intensive and uses up to 30% of one CPU core, but it leaves more than 290 KB of free memory to the application.

Graphics (Canvas) are not available, and some character styles (double size, 132 columns, italic) are not supported.

This example initializes the VGA text controller with 64 colors (16 usable): 

fabgl::VGATextController VGAController;
// the default pinout assigns GPIO22 and GPIO21 to red, GPIO19 and GPIO18 to green, GPIO5 and GPIO4 to blue, GPIO23 to HSync and GPIO15 to VSync
VGAController.begin();
VGAController.setResolution();
