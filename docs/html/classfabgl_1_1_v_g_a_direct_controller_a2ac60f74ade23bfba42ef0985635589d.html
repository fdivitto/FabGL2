Sets the current resolution using a Linux-like modeline.

The modeline has the following syntax (case-insensitive): 

"label" clock_mhz hdisp hsyncstart hsyncend htotal vdisp vsyncstart vsyncend vtotal (+HSync | -HSync) (+VSync | -VSync) [DoubleScan | QuadScan] [FrontPorchBegins | SyncBegins | BackPorchBegins | VisibleBegins] [MultiScanBlank]

fabglconf.h defines macros with predefined modelines for common resolutions. When both MultiScanBlank and DoubleScan are specified, additional rows are not repeated but filled with blank lines.

Parameters
modelineLinux-like modeline, as described above.
viewPortWidthViewport width in pixels. If negative (-1), it matches the width of the modeline visible area.
viewPortHeightViewport height in pixels. If negative (-1), it is set to the maximum height that can be allocated.
doubleBufferedIf true, a second viewport of the same size is allocated as back buffer. Make sure enough free memory is available.

Example: 

// Use the predefined modeline for 640x480@60Hz
VGAController.setResolution(VGA_640x480_60Hz);

// Same as above, using a modeline string
VGAController.setResolution("\"640x480@60Hz\" 25.175 640 656 752 800 480 490 492 525 -HSync -VSync");

// Set 640x382@60Hz but limit the viewport to 640x350
VGAController.setResolution(VGA_640x382_60Hz, 640, 350);
