Detailed Description

Composite video (PAL/NTSC) bitmapped display controller with 16 colors.

CVBS16Controller generates a composite video signal (CVBS) using the internal DAC. Each pixel is represented by 4 bits, an index into a palette of 16 colors.

Example: 

fabgl::CVBS16Controller displayController;
displayController.begin(GPIO_NUM_25);           // composite output on GPIO 25 (DAC)
displayController.setResolution("P-PAL-B");     // progressive PAL-B
