Detailed Description

PS/2 keyboard driver.

Keyboard connects to one port of the PS/2 controller (fabgl::PS2Controller) and converts scancodes to virtual keys and to ASCII (and ANSI) codes.
It can optionally create a task that waits for scancodes from the PS/2 device and puts virtual keys into a queue.
The PS/2 controller uses the ULP coprocessor and RTC slow memory to communicate with the PS/2 device.

An international keyboard layout can be selected; the default is the US layout.
The predefined layouts are US (USA), UK (United Kingdom), DE (German), IT (Italian), ES (Spanish), FR (French), BE (Belgian), NO (Norwegian) and JP (Japanese). Other layouts can be defined by deriving from US or from any other layout.

Applications usually do not create Keyboard instances: PS2Controller creates them, and they can be obtained with PS2Controller::keyboard().

Example: 

fabgl::Keyboard Keyboard;

// Use GPIO33 for CLK and GPIO32 for DATA
Keyboard.begin(GPIO_NUM_33, GPIO_NUM_32);  // clk, dat

// Print the names of the received virtual keys
while (true)
  printf("VirtualKey = %s\n", Keyboard.virtualKeyToString(Keyboard.getNextVirtualKey()));
