Detailed Description

LineEditor is a single-line editor, spanning multiple rows if needed, that uses a Terminal object for input and output.

The editor supports the following control keys:

  • Left and Right Arrow keys: move the cursor left and right, even across rows
  • CTRL + Left and Right Arrow keys: move the cursor to the beginning of the previous or next word
  • Home key: move the cursor to the beginning of the line
  • End key: move the cursor to the end of the line
  • Delete key: delete the character under the cursor
  • Insert key: toggle insert mode
  • Backspace key: delete the character to the left of the cursor
  • Enter/Return: move the cursor to the beginning of the next line and exit the editor

Example: 

Terminal.write("> ");  // show prompt
LineEditor ed(&Terminal);
char * txt = ed.get();
Terminal.printf("Your input is: %s\r\n", txt);
