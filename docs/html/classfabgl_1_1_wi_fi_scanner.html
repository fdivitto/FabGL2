Detailed Description

WiFi scanner helper class.

WiFiScanner scans for nearby WiFi networks.

Example: 

fabgl::WiFiScanner scanner;
if (scanner.scan())
  for (int i = 0; i < scanner.count(); ++i) {
    auto item = scanner.get(i);
    Term.printf("#%d %s %d dBm\r\n", i, item->ssid, item->rssi);
  }

VGA/InputBox/main/InputBox.cpp, VGA/NetworkTerminal/main/NetworkTerminal.cpp, and VGA/PCEmulator/main/PCEmulator.cpp.
