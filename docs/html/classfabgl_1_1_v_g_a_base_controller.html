Detailed Description

Base class of all VGA display controllers.

Implements GPIO assignment, modeline parsing, signal timings and screen adjustment (moveScreen(), shrinkScreen()) shared by fabgl::VGAController, fabgl::VGATextController, fabgl::VGADirectController and the palette-based controllers. Applications use one of the derived classes.
