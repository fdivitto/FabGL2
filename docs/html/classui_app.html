Detailed Description

Represents the whole application base class.

FabGL UI applications must derive from uiApp, create their UI elements in the uiApp::init() method and finally call uiApp::run() to start the application. uiApp handles the event queue, window management, and the lifecycle and memory management of windows and controls.

Examples
Composite/BaseExample/main/BaseExample.cpp, VGA/Audio/main/Audio.cpp, VGA/FileBrowser/main/FileBrowser.cpp, VGA/HardwareTest/main/HardwareTest.cpp, and VGA/VIC20/main/VIC20.cpp.
