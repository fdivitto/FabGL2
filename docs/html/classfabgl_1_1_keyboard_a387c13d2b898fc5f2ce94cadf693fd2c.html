void begin ( bool generateVirtualKeys,
bool createVKQueue,
int PS2Port )

Initializes Keyboard without initializing the PS/2 controller.

A reset command (see reset()) is automatically sent to the keyboard.
This method does not initialize the PS2Controller.

Parameters
generateVirtualKeysIf true, creates a task that consumes scancodes and produces virtual keys, so that isVKDown() can be used.
createVKQueueIf true, creates a task that consumes scancodes to produce virtual keys and puts them in a queue, so that isVKDown(), virtualKeyAvailable() and getNextVirtualKey() can be used.
PS2PortThe PS/2 port to use (0 or 1).

Example: 

// Use GPIO33 for CLK and GPIO32 for DATA on port 0
PS2Controller::begin(GPIO_NUM_33, GPIO_NUM_32); // clk, dat
Keyboard.begin(true, true, 0); // port 0
