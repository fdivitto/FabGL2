Migrating from FabGL 1.x (Arduino) to FabGL2 (ESP-IDF 6.1)

FabGL2 is a pure ESP-IDF component. Arduino core, Arduino IDE and PlatformIO "arduino" framework are no longer supported.

Project structure

FabGL 1.x FabGL2
src/, library.properties, library.json, component.mk components/fabgl/ (CMakeLists.txt, Kconfig, idf_component.yml, src/)
examples/VGA/Sprites/Sprites.ino examples/VGA/Sprites/ ESP-IDF project: CMakeLists.txt, sdkconfig.defaults, main/Sprites.cpp
setup() / loop() extern "C" void app_main() (examples still use setup()/loop() functions called by app_main())

Header names and namespaces are unchanged (#include "fabgl.h", fabgl::...).

Configuration

The PS/2 controller requires the ULP FSM coprocessor (CONFIG_ULP_COPROC_ENABLED=y, CONFIG_ULP_COPROC_TYPE_FSM=y) and at least 2112 bytes of reserved RTC slow memory (CONFIG_ULP_COPROC_RESERVE_MEM). Including the component automatically selects CONFIG_ULP_COPROC_ENABLED; the reserved memory size must be set in sdkconfig.defaults (a static_assert reports it).

Examples run app_main() on CPU 1 (CONFIG_ESP_MAIN_TASK_AFFINITY_CPU1=y) with 8KB of stack, like the Arduino loop() task, and disable the idle task watchdog on CPU 1 (CONFIG_ESP_TASK_WDT_CHECK_IDLE_TASK_CPU1=n) because many examples busy-loop.
