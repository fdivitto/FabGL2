AnsiTerminal

A complete serial VT/ANSI terminal: connect the board to a retro computer, a Z80/CP/M board (e.g. MBC2, RC2014), a Raspberry Pi, a Linux console or any device with a serial port, and use it with a VGA monitor and a PS/2 keyboard and mouse. All the settings are configured on screen and saved in NVS.

At boot the terminal shows version, screen and terminal size, keyboard layout, terminal type and serial parameters (this can be disabled with Show Info).

Default settings

Setting Default
Serial port TX = GPIO2, RX = GPIO34 (FabGL Terminal port), RTS = GPIO13, CTS = GPIO35
Serial parameters 115200 baud, 8N1, no flow control
Terminal type ANSI Legacy
Keyboard layout US
Resolution 640x480 60 Hz, 16 colors, font chosen automatically for 80x25
Colors bright green on black

Keys

Key Action
F12 Opens the Terminal Configuration dialog
Ctrl + Alt + F12 Resets all settings to the defaults and reboots
Pause/Break Sends a serial BREAK (233 ms)
Shift + Pause/Break Sends a long serial BREAK (3.5 s)

Terminal Configuration dialog (F12)

Use Tab / Shift+Tab to move between fields, or the mouse.

Field Values
Terminal Type ANSI, ADM 3A, ADM 31, Hazeltine 1500, Osborne, Kaypro, VT52, ANSI Legacy
Keyboard Layout DE, IT, UK, US, ES, FR, BE, NO, JP
Background / Foreground Color Any of the 16 terminal colors
Baud Rate 110 ... 2000000
Data Length / Parity / Stop Bits 5-8 bits / None, Even, Odd / 1, 1.5, 2, 3
Flow Control None, XON/XOFF, RTS/CTS, Combi (both)
Resolution 1280x768 B&W, 1024x720 4 colors, 800x600 8 colors, 720x520 16 colors, 640x480 73 Hz or 60 Hz 16 colors, 640x350 16 colors, 512x384 64 colors, 400x300 64 colors
Font Auto, or one of the 31 included fonts (from 4x6 to 10x20, plus decorative fonts)
Columns / Rows Max (as many as fit), 80 or 132 / Max, 24 or 25
Port FabGL Terminal (TX=2, RX=34), USB (TX=1, RX=3: the USB-serial chip, so the terminal can be driven by a PC), PS/2 Mouse (TX=27, RX=26: uses the mouse port, the mouse is disabled)
Show Info Shows the information screen at boot
RTS / CTS RTS can be toggled by clicking it; CTS shows the input line state

Buttons:

Button Action
Quit [ESC] Closes the dialog without saving
Save & Quit [F10] Saves the settings. Changes of resolution, font, columns, rows, background color or port reboot the terminal
Reboot [CTRL+ESC] Reboots the board
Install Programs Sends a sample BASIC program to the host (see below)

Install Programs

When the host runs CP/M, Install Programs types PIP <NAME>.BAS=CON: on the host and then sends the program text, so the file is saved on the host disk. Then run it with MBASIC (MBASIC <NAME>). The programs use the FabGL-specific escape sequences to control GPIOs, read the ADC, play sounds, read the mouse and draw graphics and sprites:

Program Description
BLINK.BAS Sets GPIO12 as output and turns it on and off
GPIOREAD.BAS Sets GPIO36 as digital input and continuously prints its value
ADC.BAS Sets GPIO36 as analog input and draws its value
ADCVOLTS.BAS Sets GPIO36 as analog input and prints its value in Volts
SOUND.BAS Generates some sounds
MOUSE.BAS Shows mouse position and buttons
GRAPH.BAS Draws some graphics
SPRITE.BAS Creates and moves sprites

The same programs are in Extras/Terminal BASIC Programs. The full list of FabGL sequences is in FabGL Specific Terminal Sequences.

Changing resolution from the host

The host can switch resolution by sending the user sequence ESC _ # <mode> $, where <mode> is one of 1280x768x2, 1024x720x4, 800x600x8, 720x520x16, 640x480@73x16, 640x480@60x16, 640x350x16, 512x384x64, 400x300x64. The terminal reboots in the new mode for one session only (the saved resolution is not changed). Example from MBASIC: PRINT CHR$(27);"_#800x600x8$";

What it demonstrates

  • fabgl::Terminal connected to a UART through fabgl::SerialPort and fabgl::SerialPortTerminalConnector (hardware and software flow control, BREAK)
  • Terminal emulations, fonts, colors and keyboard layouts selectable at run time
  • Choosing the display controller (2, 4, 8, 16 or 64 colors) at run time according to the resolution
  • A configuration GUI (uiApp) shown on top of the terminal, fabgl::Preferences (NVS)
  • Terminal user sequences (Terminal.onUserSequence)

Hardware

  • VGA output (default pins)
  • PS/2 keyboard on port 0 and PS/2 mouse on port 1 (optional)
  • Serial connection to the host (3.3 V logic levels; use a level shifter for RS-232 or 5 V devices)

76void setup()
77{
78 #if FABGLIB_TERMINAL_DEBUG_REPORT
79 Console.begin(); vTaskDelay(pdMS_TO_TICKS(500)); printf("\n\nReset\n\n"); // DEBUG ONLY
80 #endif
81
82
83 // more stack is required for the UI (used inside Terminal.onVirtualKey)
84 Terminal.keyboardReaderTaskStackSize = 3000;
85
86 Terminal.inputQueueSize = 2048; // 2048 good to pass vttest
87
88 preferences.begin("AnsiTerminal", false);
89
90 ConfDialogApp::checkVersion();
91
92 #if USERESETPIN
93 fabgl::configureGPIO((gpio_num_t)(RESET_PIN), GPIO_MODE_INPUT);
94 if (gpio_get_level((gpio_num_t)(RESET_PIN)) == RESET_PIN_ACTIVE)
95 preferences.clear();
96 #endif
97
98 // because mouse is optional, don't re-try if it is not found (to speed-up boot)
99 fabgl::Mouse::quickCheckHardware();
100
101 // keyboard configured on port 0, and optionally mouse on port 1
102 if (UARTPORT_FLAGS[ConfDialogApp::getUARTPortIndex()] & UARTFLAG_USE_PS2PORT1)
103 PS2Controller.begin(PS2Preset::KeyboardPort0); // mouse port used as serial port, so no mouse available
104 else
105 PS2Controller.begin(PS2Preset::KeyboardPort0_MousePort1);
106
107 ConfDialogApp::setupDisplay();
108
109 ConfDialogApp::loadConfiguration();
110
111 #if FABGLIB_TERMINAL_DEBUG_REPORT
112 Terminal.setLogStream(Console); // debug only
113 #endif
114
115 Terminal.clear();
116 Terminal.enableCursor(true);
117
118 if (ConfDialogApp::getBootInfo() == BOOTINFO_ENABLED) {
119 Terminal.write("* * FabGL - Serial Terminal * *\r\n");
120 Terminal.write("* * 2019-2026 by Fabrizio Di Vittorio - www.fabgl.com * *\r\n\n");
121 Terminal.printf("Version : %d.%d\r\n", TERMVERSION_MAJ, TERMVERSION_MIN);
122 Terminal.printf("Screen Size : %d x %d\r\n", DisplayController->getViewPortWidth(), DisplayController->getViewPortHeight());
123 Terminal.printf("Terminal Size : %d x %d\r\n", Terminal.getColumns(), Terminal.getRows());
124 Terminal.printf("Keyboard Layout : %s\r\n", PS2Controller.keyboard()->isKeyboardAvailable() ? SupportedLayouts::names()[ConfDialogApp::getKbdLayoutIndex()] : "No Keyboard");
125 //Terminal.printf("Mouse : %s\r\n", PS2Controller.mouse()->isMouseAvailable() ? "Yes" : "No");
126 Terminal.printf("Terminal Type : %s\r\n", SupportedTerminals::names()[(int)ConfDialogApp::getTermType()]);
127 //Terminal.printf("Free Memory : %d bytes\r\n", heap_caps_get_free_size(MALLOC_CAP_32BIT));
128 Terminal.printf("Serial Port : %s\r\n", UARTPORT_STR[ConfDialogApp::getUARTPortIndex()]);
129 Terminal.printf("Serial Parameters : %s\r\n", ConfDialogApp::getSerParamStr());
130
131 Terminal.write("\r\nPress F12 to change terminal configuration and CTRL-ALT-F12 to reset settings\r\n\n");
132 } else if (ConfDialogApp::getBootInfo() == BOOTINFO_TEMPDISABLED) {
133 preferences.putInt(PREF_BOOTINFO, BOOTINFO_ENABLED);
134 }
135
136 // onVirtualKey is triggered whenever a key is pressed or released
137 Terminal.onVirtualKeyItem = [&](VirtualKeyItem * vkItem) {
138 if (vkItem->vk == VirtualKey::VK_F12) {
139 // CTRL ALT F12 -> show reboot dialog
140 // F12 -> show configuration dialog
141 if (vkItem->CTRL && (vkItem->LALT || vkItem->RALT)) {
142 Terminal.deactivate();
143 preferences.clear();
144 // show reboot dialog
145 auto rebootApp = new RebootDialogApp;
146 rebootApp->run(DisplayController);
147 } else if (!vkItem->CTRL && !vkItem->LALT && !vkItem->RALT && !vkItem->down) {
148 // releasing F12 key to open configuration dialog
149 Terminal.deactivate();
150 if (PS2Controller.mouse())
151 PS2Controller.mouse()->emptyQueue(); // avoid previous mouse movements to be showed on UI
152 auto dlgApp = new ConfDialogApp;
153 dlgApp->run(DisplayController);
154 auto progToInstall = dlgApp->progToInstall;
155 // this is required, because the terminal may not cover the entire screen
156 Terminal.canvas()->reset();
157 Terminal.canvas()->setBrushColor(dlgApp->getBGColor());
158 Terminal.canvas()->fillRectangle(dlgApp->frameRect);
159 delete dlgApp;
160 Terminal.keyboard()->emptyVirtualKeyQueue();
161 Terminal.activate();
162 // it has been requested to install a demo program?
163 if (progToInstall > -1)
164 installProgram(progToInstall);
165 vkItem->vk = VirtualKey::VK_NONE;
166 }
167 } else if (vkItem->vk == VirtualKey::VK_BREAK && !vkItem->down) {
168 // BREAK (CTRL PAUSE) -> short break (TX low for 3.5 s)
169 // SHIFT BREAK (SHIFT CTRL PAUSE) -> long break (TX low for 0.233 ms)
170 SerialPort.sendBreak(true);
171 vTaskDelay((vkItem->SHIFT ? 3500 : 233) / portTICK_PERIOD_MS);
172 SerialPort.sendBreak(false);
173 vkItem->vk = VirtualKey::VK_NONE;
174 }
175 };
176
177 // onUserSequence is triggered whenever a User Sequence has been received (ESC + '_#' ... '$'), where '...' is sent here
178 Terminal.onUserSequence = [&](char const * seq) {
179 // 'R': change resolution (for example: ESC + "_#R512x384x64$")
180 for (int i = 0; i < RESOLUTIONS_COUNT; ++i)
181 if (strcmp(RESOLUTIONS_CMDSTR[i], seq) == 0) {
182 // found resolution string
183 preferences.putInt(PREF_TEMPRESOLUTION, i);
184 if (ConfDialogApp::getBootInfo() == BOOTINFO_ENABLED)
185 preferences.putInt(PREF_BOOTINFO, BOOTINFO_TEMPDISABLED);
186 esp_restart();
187 }
188 };
189}

192void loop()
193{
194 #if SHOWBREAKS
195 if (SerialPort.breakDetected()) {
196 Terminal.printf("BREAK\r\n");
197 }
198 vTaskDelay(50);
199 #else
200
201 // the job is done using UART interrupts
202 vTaskDelete(NULL);
203
204 #endif
205}
