VirtualKey getNextVirtualKey ( bool * keyDown = nullptr,
int timeOutMS = -1 )

Gets a virtual key from the queue.

Virtual keys are generated from scancodes only if the generateVirtualKeys and createVKQueue parameters of begin() are true (default).

Parameters
keyDownPointer to a boolean that receives true if the key has been pressed, false if it has been released.
timeOutMSTimeout in milliseconds. -1 = no timeout (wait forever).
Returns
The first virtual key in the queue (VK_NONE if no key is available within the timeout).
