Detailed Description

PS/2 mouse driver.

Mouse connects to one port of the PS/2 controller (fabgl::PS2Controller) and decodes mouse movements.
It supports standard PS/2 mice (X/Y axes and three buttons) and Microsoft IntelliMouse compatible mice (X/Y axes, three buttons and a scroll wheel).
Movement parameters such as sample rate, resolution and scaling can be configured.
The PS/2 controller uses the ULP coprocessor and RTC slow memory to communicate with the PS/2 device.

Since fabgl::PS2Controller supports up to two PS/2 ports, two PS/2 devices can be connected. The most common configuration is a keyboard on port 0 and a mouse on port 1, but two mice can also be connected at the same time.

Example: 

// Use GPIO26 for CLK and GPIO27 for DATA
fabgl::Mouse Mouse;
Mouse.begin(GPIO_NUM_26, GPIO_NUM_27);

if (Mouse.deltaAvailable()) {
  MouseDelta mouseDelta;
  Mouse.getNextDelta(&mouseDelta);

  printf("deltaX = %d  deltaY = %d  deltaZ = %d  leftBtn = %d  midBtn = %d  rightBtn = %d\n",
                mouseDelta.deltaX, mouseDelta.deltaY, mouseDelta.deltaZ,
                mouseDelta.buttons.left, mouseDelta.buttons.middle, mouseDelta.buttons.right);
}
