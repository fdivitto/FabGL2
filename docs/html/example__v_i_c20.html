VIC20

Emulator of the Commodore VIC-20 home computer: MOS 6502 CPU, VIC 6561 video and sound chip (PAL), two VIA 6522, memory expansions up to 35 KB, cartridges, joystick and an emulated disk drive. It includes 22 programs (games and demos) and can download many more from the Internet. Watch it on YouTube.

Getting started

At boot the emulator copies the included programs into the VIC20Store directory (on the SD card if present, otherwise on the internal SPIFFS partition) and shows the configuration screen:

  • on the left, the program list (the VIC20Store directory)
  • on the right, the buttons and the settings
  • at the bottom, the free space and the download buttons

Select a program and press Enter (or double-click it, or press Load): the emulator sets the needed RAM expansion, loads the program and runs it. Press F12 to go back to the configuration screen at any time, and F12 (or Esc) again to return to the VIC-20.

Configuration screen

Control Function
Run [F12] Runs (or resumes) the VIC-20
Load Loads and runs the selected program
Soft Reset Resets the VIC-20 (the cartridge stays inserted)
Hard Reset Removes the cartridge and resets the VIC-20
HELP [F1] Shows the keyboard shortcuts
Keyboard Layout Layout of the PS/2 keyboard (US, UK, DE, IT, ...)
RAM Expansion Unexpanded, 3K, 8K, 16K, 24K, 27K (24K+3K), 32K, 35K (32K+3K). Set automatically from the file name when a program is loaded
Joystick None, Cursor Keys or Mouse (see below)
Download From: Web Downloads all the programs listed in main/progs/weblist.h (about 90 games and cartridges from zimmers.net). Asks for the WiFi network the first time
Download From: URL Downloads a single program: type the URL and then the file name to give it (see the naming rules below)

In the program list, Del deletes the selected file or directory (asks a confirmation).

Program files and naming rules

Programs are .PRG files (loaded in RAM and started with RUN) or .CRT files (cartridge images, inserted and started with a reset). The file name tells the emulator how to load the program:

PROGNAME [EXP] [ADDRESS].EXT
Part Meaning
PROGNAME Program name
EXP RAM expansion needed: 3K, 8K, 16K, 24K, 27K, 32K, 35K. Omit it for unexpanded programs
ADDRESS Cartridges only: load address 20 (2000h), 40 (4000h), 60 (6000h) or A0 (A000h, default)
EXT PRG or CRT

Examples: Popeye 32K.PRG, Quikman 8K.PRG, Aggressor.CRT.

Cartridges made of several ROM files: give all the parts the same name with a different address, for example Battlezone 60.CRT and Battlezone A0.CRT; loading one of them loads all the parts.

You can also copy .PRG and .CRT files to the VIC20Store directory of the SD card from a PC.

Included programs: Arukanoido, Astro Panic, Blue Star, Dragonwing, Frogger07, Froggie, Kikstart, Kweepout, Nibbler, Omega Fury, Pooyan, Popeye, Pulse, Quikman, Spikes, Splatform, Tank Battalion, Tammerfors, Tetris+, and the demos Bah Bah, Birthday, Digit.

Emulated disk drive

The VIC-20 sees the VIC20Store directory as disk drive 8:

LOAD "$",8 (directory)
LIST
LOAD "NAME",8
SAVE "NAME",8

What it demonstrates

  • The fabgl::MOS6502 CPU core, with emulated VIC 6561 (video and audio), VIA 6522 and IEC serial bus drive
  • Rendering an emulated video chip on a fabgl::VGAController frame buffer
  • A GUI (uiApp, uiFileBrowser) to manage programs, settings saved with fabgl::Preferences
  • HTTP and HTTPS downloads with fabgl::HTTPRequest (see the TLS memory settings in sdkconfig.defaults)

Hardware

  • VGA output (default pins)
  • Audio output on GPIO25
  • PS/2 keyboard on port 0, optional PS/2 mouse on port 1
  • Optional SD card (TTGO VGA32 slot)

Build

The example ships a partitions.csv (3 MB application + SPIFFS). See Building the examples.

151// copies embedded programs into SPIFFS/SDCard
152void copyEmbeddedPrograms()
153{
154 FileBrowser dir(basepath);
155 if (!dir.exists(EMBDIR, false)) {
156 // there isn't a EMBDIR folder, create and populate it
157 dir.makeDirectory(EMBDIR);
158 dir.changeDirectory(EMBDIR);
159 for (int i = 0; i < sizeof(embeddedProgs) / sizeof(EmbeddedProgDef); ++i) {
160 int fullpathlen = dir.getFullPath(embeddedProgs[i].filename);
161 char fullpath[fullpathlen];
162 dir.getFullPath(embeddedProgs[i].filename, fullpath, fullpathlen);
163 FILE * f = fopen(fullpath, "wb");
164 if (f) {
165 fwrite(embeddedProgs[i].data, 1, embeddedProgs[i].size, f);
166 fclose(f);
167 }
168 }
169 }
170}

601 // extract required RAM size from selected filename (a space and 3K, 8K...)
602 void setSelectedProgramConf()
603 {
604 char const * fname = fileBrowser->filename();
605 if (fname) {
606 // select required memory expansion
607 static char const * EXP[8] = { "", " 3K", " 8K", " 16K", " 24K", " 27K", " 32K", " 35K" };
608 int r = 0;
609 for (int i = 1; i < 8; ++i)
610 if (strstr(fname, EXP[i])) {
611 r = i;
612 break;
613 }
614 RAMExpComboBox->selectItem(r);
615 }
616 }
617
618 // extract address from selected filename. "20"=0x2000, "40"=0x4000, "60"=0x6000 or "A0"=0xA000, "A0" or automatic is the default
619 // addrPos if specified will contain where address has been found
620 int getAddress(char * filename, char * * addrPos = nullptr)
621 {
622 static char const * ASTR[] = { " 20", " 40", " 60", " a0", " A0" };
623 static const int ADDR[] = { 0x2000, 0x4000, 0x6000, 0xa000, 0xa000 };
624 for (int i = 0; i < sizeof(ADDR) / sizeof(int); ++i) {
625 auto p = strstr(filename, ASTR[i]);
626 if (p) {
627 if (addrPos)
628 *addrPos = p + 1;
629 return ADDR[i];
630 }
631 }
632 return -1;
633 }
634
635 // configuration given by filename:
636 // PROGNAME[EXP][ADDRESS].EXT
637 // PROGNAME : program name (not included extension)
638 // EXP : expansion ("3K", "8K", "16K", "24K", "27K", "32K", "35K")
639 // ADDRESS : hex address ("20"=0x2000, "40"=0x4000, "60"=0x6000 or "A0"=0xA000), "A0" or automatic is the default
640 // EXT : "CRT" or "PRG"
641 bool loadSelectedProgram()
642 {
643 bool backToVIC = false;
644 char const * fname = fileBrowser->filename();
645 if (fname) {
646 FileBrowser & dir = fileBrowser->content();
647
648 bool isPRG = strstr(fname, ".PRG") || strstr(fname, ".prg");
649 bool isCRT = strstr(fname, ".CRT") || strstr(fname, ".crt");
650
651 if (isPRG || isCRT) {
652
653 machine->removeCRT();
654
655 int fullpathlen = dir.getFullPath(fname);
656 char fullpath[fullpathlen];
657 dir.getFullPath(fname, fullpath, fullpathlen);
658
659 if (isPRG) {
660 // this is a PRG, just reset, load and run
661 machine->loadPRG(fullpath, true, true);
662 } else if (isCRT) {
663 // this a CRT, find other parts, load and reset
664 char * addrPos = nullptr;
665 int addr = getAddress(fullpath, &addrPos);
666 if (addrPos) {
667 // address specified, try to load all possible positions (2000, 4000, 6000 and a000)
668 static const char * POS = { "246Aa" }; // 2=2000, 4=4000, 6=6000, A=a000
669 for (int i = 0; i < sizeof(POS); ++i) {
670 *addrPos = POS[i]; // actually replaces char inside "fullpath"
671 machine->loadCRT(fullpath, true, getAddress(fullpath));
672 }
673 } else {
674 // no address specified, just load it
675 machine->loadCRT(fullpath, true, addr);
676 }
677 }
678 backToVIC = true;
679 }
680 }
681 return backToVIC;
682 }

716 // download specified filename from URL
717 bool downloadURL(char const * URL, char const * filename)
718 {
719 //printf("Downloading %s from %s\n", filename, URL);
720 FileBrowser & dir = fileBrowser->content();
721 if (dir.exists(filename, false)) {
722 return true;
723 }
724 bool success = false;
725 fabgl::HTTPRequest http;
726 int httpCode = http.open(URL);
727 if (httpCode == 200) {
728
729 int fullpathLen = dir.getFullPath(filename);
730 char fullpath[fullpathLen];
731 dir.getFullPath(filename, fullpath, fullpathLen);
732 FILE * f = fopen(fullpath, "wb");
733
734 if (f) {
735 int len = http.contentLength();
736 constexpr int BUFSIZE = 1024;
737 uint8_t * buf = (uint8_t*) malloc(BUFSIZE);
738 int dsize = 0;
739 while (len > 0 || len == -1) {
740 int c = http.read(buf, BUFSIZE);
741 if (c <= 0)
742 break;
743 fwrite(buf, c, 1, f);
744 dsize += c;
745 if (len > 0)
746 len -= c;
747 }
748 free(buf);
749 fclose(f);
750 success = (len == 0 || (len == -1 && dsize > 0));
751 if (!success)
752 remove(fullpath); // don't leave a partial file, it would look already downloaded
753 }
754 }
755 //printf("Download %s\n", success ? "OK" : "Failed");
756 return success;
757 }
