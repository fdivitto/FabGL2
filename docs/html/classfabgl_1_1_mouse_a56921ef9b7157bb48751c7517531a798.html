void begin ( gpio_num_t clkGPIO,
gpio_num_t dataGPIO )

Initializes Mouse, specifying the CLOCK and DATA GPIOs.

A reset command (see reset()) is automatically sent to the mouse.
This method also initializes PS2Controller to use port 0 only.

Since the PS/2 ports are handled by the ULP coprocessor, only a few GPIOs can be used: GPIO_NUM_2, GPIO_NUM_4, GPIO_NUM_12 (with some limitations), GPIO_NUM_13, GPIO_NUM_14, GPIO_NUM_15, GPIO_NUM_25, GPIO_NUM_26, GPIO_NUM_27, GPIO_NUM_32 and GPIO_NUM_33.

Parameters
clkGPIOGPIO of the clock line
dataGPIOGPIO of the data line

Example: 

// Use GPIO26 for CLK and GPIO27 for DATA
Mouse.begin(GPIO_NUM_26, GPIO_NUM_27);
