◆ format()

bool format ( DriveType driveType,
int drive )
static

Formats SPIFFS or SD Card.

The filesystem must be mounted before calling format(). At the end of formatting the filesystem is unmounted, so it must be mounted again.

Parameters
driveTypeStorage type (SPI Flash or SD Card).
driveDrive number (can be 0 when only one filesystem is mounted)
Returns
True on success.

Example: 

// Format SPIFFS and remount it
FileBrowser::format(fabgl::DriveType::SPIFFS, 0);
FileBrowser::mountSPIFFS(false, "/spiffs");
