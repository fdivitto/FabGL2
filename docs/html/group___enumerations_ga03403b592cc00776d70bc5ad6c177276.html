Native pixel formats of the display controllers.

Enumerator
SBGR2222 

8 bits per pixel: VHBBGGRR (bit 7=VSync 6=HSync 5=B 4=B 3=G 2=G 1=R 0=R). Each color channel ranges from 0 to 3 (maximum intensity).

PALETTE2 

1 bit palette (2 colors), packed as 8 pixels per byte.

PALETTE4 

2 bit palette (4 colors), packed as 4 pixels per byte.

PALETTE8 

3 bit palette (8 colors), packed as 8 pixels every 3 bytes.

PALETTE16 

4 bit palette (16 colors), packed as two pixels per byte.
