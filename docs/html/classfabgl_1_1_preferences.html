Detailed Description

Simple key/value storage in non-volatile flash (NVS).

A thin wrapper over the ESP-IDF NVS API. Each Preferences object works on one NVS namespace. nvs_flash_init() is called automatically when needed.

Example: 

fabgl::Preferences preferences;
preferences.begin("MyApp");
int value = preferences.getInt("counter", 0);
preferences.putInt("counter", value + 1);
