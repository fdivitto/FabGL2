SimpleTextTerminalOut

Same as SimpleTerminalOut, but using fabgl::VGATextController, the text-only VGA mode (80x25 characters, 16 colors) that needs only a few KB of RAM.

The demo cycles through: welcome screen (screen and terminal size, free memory), the 16 ANSI foreground and background colors, the supported styles (bold, underlined, blinking, inverse) and a fast VT/ANSI animation. There are no controls.

What it demonstrates

  • fabgl::Terminal on top of fabgl::VGATextController
  • What the text-only mode can and cannot do compared to a graphical controller: no italic, no double width or double height lines, no graphics, but a much smaller memory footprint (useful when the application needs RAM for other purposes, e.g. WiFi)

Hardware

  • VGA output (default pins)

Build

See Building the examples.

52void slowPrintf(const char * format, ...)
53{
54 va_list ap;
55 va_start(ap, format);
56 int size = vsnprintf(nullptr, 0, format, ap) + 1;
57 if (size > 0) {
58 va_end(ap);
59 va_start(ap, format);
60 char buf[size + 1];
61 vsnprintf(buf, size, format, ap);
62 for (int i = 0; i < size; ++i) {
63 Terminal.write(buf[i]);
64 vTaskDelay(pdMS_TO_TICKS(25));
65 }
66 }
67 va_end(ap);
68}

139void demo5()
140{
141 Terminal.write("\e[40;93m"); // background: black, foreground: yellow
142 Terminal.write("\e[2J"); // clear screen
143 slowPrintf("\e[10;56HFast Rendering");
144 slowPrintf("\e[12;50HThis is a VT/ANSI animation");
145 Terminal.write("\e[20h"); // automatic new line on
146 Terminal.write("\e[92m"); // light-green
147 Terminal.enableCursor(false);
148 for (int j = 0; j < 4; ++j) {
149 for (int i = 0; i < sizeof(vt_animation); ++i) {
150 Terminal.write(vt_animation[i]);
151 if (vt_animation[i] == 0x1B && vt_animation[i + 1] == 0x5B && vt_animation[i + 2] == 0x48)
152 vTaskDelay(pdMS_TO_TICKS(120)); // pause 100ms every frame
153 }
154 }
155 Terminal.enableCursor(true);
156 Terminal.write("\e[20l"); // automatic new line off
157}
