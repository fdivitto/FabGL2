PCEmulator

IBM PC/XT emulator: Intel 8086/8088 CPU, 1 MB of RAM, CGA (text, 320x200 and 640x200 graphics) and Hercules (720x348) video, PC speaker, PS/2 keyboard and mouse, two floppy drives, two hard disks and a serial port. It runs MS-DOS, FreeDOS, CP/M-86, Linux ELKS, Windows 3.0, GEM, GEOS and many DOS programs and games. Watch it on YouTube.

Requirements

  • An ESP32 board with PSRAM (the emulated RAM lives in PSRAM), for example TTGO VGA32 v1.4 or the Olimex ESP32-SBC-FabGL
  • An SD card (FAT32): disk images and the machine configurations are stored on it
  • WiFi, the first time, to download the disk images (or copy them to the SD card from a PC)
  • VGA monitor, PS/2 keyboard, optional PS/2 mouse, audio on GPIO25 for the PC speaker

Getting started

  1. Insert the SD card and flash the example.
  2. If the date and time are not known yet (cold boot) the emulator asks to configure the WiFi: choose a network and type the password. The time is taken from an NTP server (pool.ntp.org) and the board restarts. Without WiFi the date is set to 14 August 1984.
  3. The Machine Configurations list appears. Choose a machine and press Run (if you do nothing, the last used machine starts after 6 seconds).
  4. If the disk images of the machine are not on the SD card yet, they are downloaded from www.fabglib.org (a progress bar shows the progress; big images take some minutes, interrupted downloads are resumed automatically). After the download the board restarts and boots the machine.

The configuration editor has these fields:

Field Meaning
Description Name shown in the list
Floppy 0 / Floppy 1 Image of drive A: / B: (a file on the SD card, or an HTTP / HTTPS URL to download it)
HDD 0 / HDD 1 Image of the first / second hard disk (C: / D:), with its geometry (Cylinders, Heads, Sectors; leave 0 to compute it from the file size)

... Selects an image file from the SD card

The configurations are saved in mconfs.txt in the root of the SD card. It is a text file, one machine per line, that can also be edited on a PC:

desc "FreeDOS (A:) + DOS Programming Tools (C:)" fd0 https://www.fabglib.org/downloads/floppy_FREEDOS.img hd0 https://www.fabglib.org/downloads/hd20_DOSDEV.img
desc "My Own MSDOS" hd0 HDD_10M.IMG chs0 306,4,17 boot hd0
desc "Machine1" fd0 msdos3/disk1.img

Tags: desc (description), fd0 / fd1 (floppy A / B), hd0 / hd1 (hard disks), chs0 / chs1 (hard disk geometry: cylinders,heads,sectors), boot (fd0, fd1, hd0, hd1; default fd0). File names are relative to the SD card root. Delete mconfs.txt to restore the predefined list.

Using images

  • Floppy images must be raw sector images (.img, .ima) of 160K, 180K, 320K, 360K, 720K, 1.2M, 1.44M or 2.88M.
  • Hard disk images are raw images (no VHD header). When no geometry is given, it is computed from the file size (63 sectors per track, up to 16 heads). If the image was partitioned with a different geometry, specify it with chs0 / chs1 (or in the Cyls / Head / Sect fields).
  • To exchange files with a PC, create a floppy image (Create Disk), mount it on the PC (e.g. with a disk image tool or mtools), copy the files, put it back on the SD card and mount it in the emulator (see Mount Disk below).

The PS/2 mouse is seen by the PC as a PS/2 mouse: load a DOS mouse driver that supports PS/2 mice (for example CTMOUSE) to use it in DOS programs.

Serial port and I/O expander

  • COM1 is connected to the USB serial port (TX = GPIO1, RX = GPIO3): use a terminal program on the PC to talk with DOS programs (for example CTTY COM1, or a communication program).
  • If a MCP23S17 GPIO expander is connected, its pins are available on the I/O ports E0h...E9h. See the GW-BASIC and QBasic examples in Extras/PC Emulator BASIC Programs.

What it demonstrates

  • The fabgl::i8086 CPU core and the emulated chips of the library: PIC8259, PIT8253, i8042 (keyboard and mouse controller), PC8250 (UART), MC146818 (RTC), and the CGA/Hercules GraphicsAdapter rendered with VGADirectController
  • PSRAM mapped and accessed directly as emulated RAM (CONFIG_SPIRAM_USE_MEMMAP)
  • fabgl::InputBox for the setup UI, fabgl::HTTPRequest for HTTPS downloads with resume (HTTP Range), WiFi + SNTP for the real-time clock
  • Running network and SD card work on the core not used by the VGA interrupt (CoreUsage::quietCore())

Build

The example ships a partitions.csv with a 3 MB application partition, and an sdkconfig.defaults that enables PSRAM. See Building the examples.

86// try to connected using saved parameters
87bool tryToConnect()
88{
89 bool connected = wifi.state() == fabgl::WiFiConnectionState::Connected;
90 if (!connected) {
91 char SSID[32] = "";
92 char psw[32] = "";
93 if (preferences.getString("SSID", SSID, sizeof(SSID)) && preferences.getString("WiFiPsw", psw, sizeof(psw))) {
94 ibox.progressBox("", "Abort", true, 200, [&](fabgl::ProgressForm * form) {
95 wifi.connect(SSID, psw, 0); // just start connection
96 for (int i = 0; i < 32 && wifi.state() != fabgl::WiFiConnectionState::Connected; ++i) {
97 if (!form->update(i * 100 / 32, "Connecting to %s...", SSID))
98 break;
99 vTaskDelay(pdMS_TO_TICKS(500));
100 }
101 connected = (wifi.state() == fabgl::WiFiConnectionState::Connected);
102 });
103 // show to user the connection state
104 if (!connected) {
105 wifi.disconnect();
106 ibox.message("", "WiFi Connection failed!");
107 }
108 }
109 }
110 return connected;
111}

183void updateDateTime()
184{
185 // Set timezone
186 setenv("TZ", "CET-1CEST,M3.5.0,M10.5.0/3", 1);
187 tzset();
188
189 // get datetime from savedTimeValue? (noinit section)
190 if (esp_reset_reason() == ESP_RST_SW) {
191 // adjust time taking account elapsed time since ESP32 started
192 savedTimeValue.tv_usec += (int) esp_timer_get_time();
193 savedTimeValue.tv_sec += savedTimeValue.tv_usec / 1000000;
194 savedTimeValue.tv_usec %= 1000000;
195 settimeofday(&savedTimeValue, nullptr);
196 return;
197 }
198
199 if (checkWiFi()) {
200
201 // we need time right now
202 ibox.progressBox("", nullptr, true, 200, [&](fabgl::ProgressForm * form) {
203 esp_sntp_setoperatingmode(SNTP_OPMODE_POLL);
204 esp_sntp_setservername(0, "pool.ntp.org");
205 esp_sntp_init();
206 for (int i = 0; i < 12 && sntp_get_sync_status() != SNTP_SYNC_STATUS_COMPLETED; ++i) {
207 form->update(i * 100 / 12, "Getting date-time from SNTP...");
208 vTaskDelay(pdMS_TO_TICKS(500));
209 }
210 esp_sntp_stop();
211 ibox.setAutoOK(2);
212 ibox.message("", "Date and Time updated. Restarting...");
213 #ifndef FABGL_EMULATED
214 esp_restart();
215 #endif
216 });
217
218 } else {
219
220 // set default time
221 struct tm tm = { };
222 tm.tm_hour = 8;
223 tm.tm_mday = 14;
224 tm.tm_mon = 7;
225 tm.tm_year = 84;
226 timeval now = { };
227 now.tv_sec = mktime(&tm);
228 settimeofday(&now, nullptr);
229
230 }
231}

234// state shared between downloadURL() and downloadTask()
235struct DownloadJob {
236 char const * URL;
237 FILE * file;
238 volatile int64_t received;
239 volatile int64_t total; // -1 = unknown
240 volatile int retries; // reconnections done
241 volatile bool abort; // set by the UI
242 volatile bool success;
243 SemaphoreHandle_t done;
244};
245
246
247// Downloads URL into job->file. Runs on the core used by WiFi (the VGA signal is generated by the other core),
248// so network, TLS and SD card work don't delay the video interrupt.
249// A connection that stalls or drops is reopened and the download resumes from the received bytes (HTTP Range).
250static void downloadTask(void * arg)
251{
252 constexpr int MAXRETRIES = 10; // consecutive reconnections without receiving data
253
254 auto job = (DownloadJob *) arg;
255 auto buf = (uint8_t*) SOC_EXTRAM_DATA_LOW; // use PSRAM as buffer (the machine isn't running yet)
256 bool writeError = false;
257 int failures = 0;
258
259 // WiFi power save (modem sleep) limits the download speed. Disable it during the download (the board restarts
260 // without WiFi after downloading, so the emulator isn't affected).
261 wifi_ps_type_t savedPS = WIFI_PS_MIN_MODEM;
262 esp_wifi_get_ps(&savedPS);
263 esp_wifi_set_ps(WIFI_PS_NONE);
264
265 fabgl::HTTPRequest http;
266 while (!job->abort && !writeError && failures <= MAXRETRIES) {
267 if (failures > 0) {
268 job->retries = job->retries + 1;
269 vTaskDelay(pdMS_TO_TICKS(1000));
270 }
271 int64_t offset = job->received;
272 int status = http.open(job->URL, offset);
273 if (status != 200 && status != 206)
274 ESP_LOGW("download", "open at %lld: HTTP status %d", (long long) offset, status);
275 if (offset == 0 && status == 200) {
276 job->total = http.contentLength();
277 } else if (offset > 0 && status == 206) {
278 // resumed
279 } else if (offset > 0 && status == 200) {
280 // server ignores Range: restart from the beginning
281 if (fseek(job->file, 0, SEEK_SET) != 0)
282 break;
283 job->received = 0;
284 job->total = http.contentLength();
285 } else if (status >= 400 && status < 500 && status != 408 && status != 429) {
286 break; // permanent error (not found, forbidden...)
287 } else {
288 ++failures;
289 http.close();
290 continue;
291 }
292 // read until the connection fails or ends
293 while (!job->abort) {
294 int c = http.read(buf, 16384);
295 if (c <= 0) {
296 if (c < 0 || (job->total >= 0 && job->received < job->total))
297 ESP_LOGW("download", "read returned %d at %lld", c, (long long) job->received);
298 break;
299 }
300 if (fwrite(buf, 1, c, job->file) != c) {
301 ESP_LOGE("download", "SD card write failed at %lld (errno %d)", (long long) job->received, errno);
302 writeError = true;
303 break;
304 }
305 job->received = job->received + c;
306 failures = 0;
307 }
308 http.close();
309 if (job->total >= 0 ? job->received >= job->total : (job->received > 0 && !writeError)) {
310 job->success = !job->abort && !writeError;
311 break;
312 }
313 ++failures;
314 }
315
316 esp_wifi_set_ps(savedPS);
317 xSemaphoreGive(job->done);
318 vTaskDelete(nullptr);
319}

322// download specified filename from URL
323bool downloadURL(char const * URL, FILE * file)
324{
325 downloadOK = false;
326 if (!file)
327 return false;
328
329 char const * filename = strrchr(URL, '/') + 1;
330
331 DownloadJob job = { };
332 job.URL = URL;
333 job.file = file;
334 job.total = -1;
335 job.done = xSemaphoreCreateBinary();
336
337 ibox.progressBox("", "Abort", true, 380, [&](fabgl::ProgressForm * form) {
338 form->update(0, "Preparing to download %s", filename);
339 // the UI task stays on this core, the download runs on the other one
340 if (xTaskCreatePinnedToCore(downloadTask, "download", 8192, &job, 5, nullptr, CoreUsage::quietCore() < 0 ? 0 : CoreUsage::quietCore()) != pdPASS)
341 return;
342 while (xSemaphoreTake(job.done, pdMS_TO_TICKS(250)) == pdFALSE) {
343 int64_t received = job.received;
344 int64_t total = job.total;
345 bool cont;
346 if (job.retries > 0)
347 cont = form->update(total > 0 ? received * 100 / total : 0, "Downloading %s (%.2f / %.2f MB) retry %d", filename, received / 1048576.0, total / 1048576.0, job.retries);
348 else
349 cont = form->update(total > 0 ? received * 100 / total : 0, "Downloading %s (%.2f / %.2f MB)", filename, received / 1048576.0, total / 1048576.0);
350 if (!cont)
351 job.abort = true; // the task ends after the current read (at most the network timeout)
352 }
353 downloadOK = job.success;
354 });
355
356 vSemaphoreDelete(job.done);
357 return downloadOK;
358}

361// return filename if successfully downloaded or already exist
362char const * getDisk(char const * url)
363{
364 FileBrowser fb(SD_MOUNT_PATH);
365
366 char const * filename = nullptr;
367 if (url) {
368 if (strncmp("http://", url, 7) == 0 || strncmp("https://", url, 7) == 0) {
369 // this is actually an URL
370 filename = strrchr(url, '/') + 1;
371 if (filename && !fb.exists(filename, false)) {
372 // disk doesn't exist, try to download
373 if (!checkWiFi())
374 return nullptr;
375 auto file = fb.openFile(filename, "wb");
376 bool success = downloadURL(url, file);
377 fclose(file);
378 if (!success) {
379 fb.remove(filename);
380 return nullptr;
381 }
382 }
383 } else {
384 // this is just a file
385 if (fb.filePathExists(url))
386 filename = url;
387 }
388 }
389 return filename;
390}
